# 小黑盒运营插件（heybox-operator）

> 本项目是 [HannJia/xiaoheihe-operator](https://github.com/HannJia/xiaoheihe-operator) 的**二创版本**（MIT License，保留原作者版权）。在原版基础上做了本地定制，主要差异：

- **修复 link_tag bug**：纯文字帖原先给 `21`（非法值）会被小黑盒拒，改为 `28`（默认动态）。正确映射：图文=27、动态=28、文章=11。
- **发帖社区/话题分离**：社区下拉（真实社区）+ 热门话题标签（`#标签`）分开选，话题支持自定义填写。
- **浏览不再锁死「游戏」**：去掉「游戏关键词」硬过滤，浏览/互动范围改由「社区白名单」决定。
- **自动发帖自由发挥**：不再写死「游戏日常」方向，由人设 + 生活轨迹自由生成内容。
- **配图直连自建生图 API**：新增 `image_generation.py`，直接调 OpenAI 兼容 `/images/generations`，可用 MaiBot 已加载的画图模型，也可单独填中转站，不依赖「麦麦绘图」插件。
- **生活轨迹联动「生活频率」**：因生活频率插件无 `get_current_context` API，改为直接读其 `life_state.json` 状态文件。

# 小黑盒运营插件

这个插件让 MaiBot 用自己的人设在小黑盒逛帖、点赞、评论和发帖，可联动生活轨迹、社区话题和自建生图能力。它使用 MaiBot 官方插件 Runner、独立 SQLite 状态库和小黑盒客户端，不修改 QQ 主链数据。

## 人设

评论、回复和帖子默认使用 MaiBot 主配置里的昵称（`bot.nickname`）和人格设定（`personality.personality`），和 MaiBot 在 QQ 上回复时用的是同一份人设；在 WebUI 改人设或切换人设方案后，插件最多一分钟内跟上，不用重启。想让小黑盒上的身份或口吻不一样时，在配置页「内容与插件联动」里填写“小黑盒人设（可选）”，填写后只影响本插件。两者都读不到时使用一句中性人设。插件为此声明了 `config.get` 能力，只读取这两个字段。

## 默认运营状态

发布版默认是 `enabled = true`、`mode = "auto"`、每天最多主动发 1 帖。发帖目标由「发帖社区」下拉框（真实社区）+「发帖话题标签」（热门 `#标签`）共同决定。首次安装或更换账号后，应先确认登录状态、社区目标和内容边界；需要只读验收时，把运行模式改成 `dry_run` 或把每日额度设为 0。

主要限制包括每日发帖/评论/通知回复配额、账号级冷却、社区白名单、内容重复键、敏感/技术内容拦截、发送结果未知状态以及认证失效和限流退避。

## 配置说明

MaiBot WebUI 的插件配置页会显示每个字段的中文用途说明。推荐流浏览间隔默认是 600 秒（10 分钟），这是本插件为新用户提供的推荐值，不是小黑盒官方固定检查时间；可以根据账号活跃度、请求频率和模型额度自行调整。实际间隔在该值的 0.5–1.5 倍之间随机，每次按推荐流顺序点开 2–4 篇，大多只看不评；评论和点赞只给命中「社区白名单」（及可选的「浏览内容关键词」）的帖子，当天的评论额度会摊到剩下的浏览场次里，不会集中在上午用完。点赞默认每天最多 3 个（`likes_per_day`），同一帖子只赞一次。插件重启后第一次浏览会推迟 2–15 分钟。联动「生活频率」时，她在睡觉或小睡就不逛也不发帖。`auto` 只有在插件启用、每日发帖数大于 0 且至少选择了一个发帖社区时才会真实发帖；`dry_run` 只生成计划，不产生小黑盒写入。为控制活跃时段，新安装默认只在服务器本地时间 08:00–23:00 浏览推荐流和主动评论、10:00–22:00 主动发帖；两个时间窗口相互独立，时间间隔和时间窗口都可以在配置页修改。起止时间相同表示全天，结束时间早于开始时间表示跨午夜。

私信功能不属于当前发布范围，默认关闭。小黑盒私信发送依赖独立的客户端聊天界面，当前没有稳定、可复用的公开发送契约；插件不会把私信误判成评论，也不会盲目重试发送。未来方案和取舍见 [私信方案记录](docs/PRIVATE_MESSAGE_OPTIONS.md)。

主动运营默认 fail-closed：`community_allowlist`（社区白名单）默认是“PC游戏”和“盒友杂谈”，浏览和主动互动只在这些社区里进行；`post_target_primary`（发帖社区）为空时不主动发帖。配置页使用中文选项，插件会在发送前按准确名称查询小黑盒并解析内部 topic ID，不要求用户手工填写数字。

发帖目标分为两类：
- **发帖社区**（`post_target_primary`）：下拉框，列出小黑盒真实社区（AI、数码硬件、校园生活、盒友杂谈、Steam、PC游戏 等），单帖选一个社区。
- **发帖话题标签**（`post_target_secondary` + `custom_hashtags`）：下拉框列出热门 `#标签`（盒友日常、单机游戏、ai 等），也可以自由填写自定义标签（逗号分隔）。留空则不挂话题。

社区白名单最多选择 10 个社区。发帖社区/话题解析失败时会跳过本轮发送，不会把内容发到不确定的分区。旧版配置中的数字 ID 仍可读取，旧版逗号分隔字符串会自动迁移。

评论回复会先读取原帖标题、正文和收到的评论，再交给内容生成器，因此在自己发布的帖子下回复时会围绕该帖内容作答。当前已支持小黑盒通知中心里的提及、评论和楼中楼回复；私信保持关闭。当前开发状态和已知限制见 [项目状态](docs/PROJECT_STATUS.md)。

## 登录

启用插件后，打开 MaiBot WebUI 中的“小黑盒运营”工作区即可直接生成二维码、扫码并轮询确认状态。二维码由插件内置的无依赖编码器生成，原始登录 URL 不显示在页面上。

也可以在 MaiBot 聊天中使用：

- `/xhh_login`：生成登录会话，并提示打开 WebUI 工作台扫码。
- `/xhh_login_check`：检查二维码状态。
- `/xhh_status`：查看插件运行模式。

凭证只写入 MaiBot 数据目录下本插件专用的 `credentials/`，日志不会打印 Cookie、Token 或二维码内容。

## 联动

本版本对三处联动做了本地化改造，都不再是硬依赖：

### 配图（自建生图 API）

主动帖子配图**不再依赖「麦麦绘图」插件**。新增 `image_generation.py`，直接调用 OpenAI 兼容的生图接口（`POST /images/generations`）。配置页三个字段：

- `image_api_base_url`：生图接口地址（如 `https://ai.feiyuapi.top/v1`）
- `image_api_key`：生图中转站密钥
- `image_model`：生图模型名（如 `gpt-image-2.5-flare-native`）

三个字段都留空时，插件会自动读取 MaiBot 主配置 `model_config.toml` 里 `api_provider` 名为「画图」的中转站及其模型。生图失败（超时、上传失败等）会记录 `image_fallback` 审计标记并降级为纯文字发帖，不会阻塞发帖，也不会用新 `request_id` 重复生成。

### 生活轨迹（读生活频率状态文件）

生活轨迹通过「生活频率」插件（ID：`org.orge-8.life-frequency`）获取。注意：生活频率最新版**没有 `get_current_context` 这个 API**（原版写错了），本版本改为**直接读取它的状态文件** `data/plugins/org.orge-8.life-frequency/life_state.json`，把 `activity`/`scene`/`emotion`/`energy` 拼成一句“当前生活轨迹”。读不到时退回服务器当前时间和已有设定。

### 身份参考图

通过「自我身份档案」（ID：`org.mai-mai.self-identity`）的 `get_default_reference_image` 获取，只在生成图片时作为参考图使用，未安装时自动跳过。

这三个联动现在都是可选的，不会阻止小黑盒运营插件单独安装和加载。

## 外部数据处理

主动帖子使用的生成图片和身份参考图（仅在插件 API 返回 base64 图片数据时读取）会通过小黑盒的上传接口发送到其使用的腾讯云 COS（通常为 `*.myqcloud.com`）以便在帖子正文中展示。插件不会根据插件 API 返回的任意本地 `path` 或 `file_path` 读取文件；需要传图的依赖应返回 base64 或图片字节。登录凭证仍只保存在 MaiBot 数据目录的本插件专用目录中。

## 验证

插件目录的测试覆盖 SQLite 幂等、内容边界、通知解析、绘图 API、媒体签名和 Runner 加载。真实账号验收必须先保持低额度，并确认发帖/评论读回后再扩大范围。

## 安装与发布

插件仓库根目录必须保留 `_manifest.json`、`plugin.py`、`LICENSE` 和 `README.md`。发布版本时，Git tag、GitHub Release 和 `_manifest.json` 的版本号必须保持一致。插件市场提交方式参见 MaiBot 官方“发布插件”文档。

## 当前发布范围

- 已纳入：扫码登录、跟随宿主人设、推荐流不定时浏览、按社区白名单浏览互动、点赞、图文发帖、评论和楼中楼回复、配额/冷却/幂等/读回核验、生活轨迹联动和自建生图 API。
- 默认开启：低额度真实自动运营，默认每天最多发 1 帖，发帖社区默认「AI」。
- 默认关闭：私信功能。真实写入前仍应确认账号登录、目标社区和生成内容符合预期。
- 暂不纳入：手机模拟器或实体手机代理。相关方案只记录在文档中，不会在插件市场版本中偷偷启用。
